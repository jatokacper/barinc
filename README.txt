BAR INC. 5.3 — IKONA I NAZWA DLA iPHONE / GITHUB PAGES

1. Rozpakuj ZIP.
2. W repozytorium GitHub Pages nadpisz pliki index.html, sw.js, manifest.webmanifest
   oraz trzy pliki w folderze icons/ (icon-180.png, icon-192.png, icon-512.png).
3. Zachowaj ten sam adres strony i istniejącą ikonę aplikacji do czasu
   wykonania kopii zapisu w Opcje -> Pobierz JSON.
4. Po aktualizacji PWA powinna pobrać nową wersję gry bez kasowania zapisu.
5. iPhone może zachować starą grafikę ikony na ekranie głównym.
   Przed jej usunięciem KONIECZNIE wyeksportuj zapis JSON w starej aplikacji;
   następnie dodaj ponownie skrót z Safari, a jeśli potrzebne, zaimportuj kopię JSON.

Zgodność zapisów: klucz localStorage pozostaje barinc_3_pixel_tycoon_v1.
Adres startowy: ./index.html (bez zmian). Cache: barinc-v53-new-icon.
